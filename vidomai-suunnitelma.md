# Vidomai.fi – kotisivujen suunnitelma

## Perustiedot
- **Yritys:** Vidomai
- **Nimen tausta:** Video + Domain + AI → Vidomai
- **Nykytila:** Sivut tällä hetkellä WordPressillä, Louhen hostingissa. Sähköposti myös sieltä (siirretään myöhemmin).
- **Uusi toteutus:** GitHub + VS Code + Claude Code
- **Yrittäjä:** Yksinyrittäjä

## Yrityksen toimiala (virallinen kuvaus)
IT-palveluiden tuottaminen yrityksille ja yhteisöille, mukaan lukien verkkosivujen ja digitaalisten palveluiden suunnittelu, toteutus ja ylläpito. Lisäksi toimialaan kuuluu video- ja muun digitaalisen sisällön tuotanto, verkko-opetusmateriaalien ja verkkokurssien toteutus, domain- ja web-palvelut sekä niihin liittyvä myynti ja konsultointi.

## Palvelut

### 1. Domain-myynti
- Puhelinmyyntiä valikoiduille, olemassa oleville yrityksille
- Esimerkki: yritys käyttää esim. `esimerkkikeskus.fi` → tarjotaan `esimerkki.fi` / `.com` / `.net` / `.eu` -pakettia (usein pelkkä `.com`)
- Liikenne käännetään ostetulta domainilta asiakkaan nykyiselle sivulle
- Hinnoittelu: n. 30 €/vuosi domainista, mutta ei kannata näyttää verkkosivulla (halvempi kuin suoraan ostettuna) – myynti perustuu puheluun, tarjoukseen, varaukseen ja kääntöön, ei verkkokauppaan
- **Sivuille:** mainitaan palveluna, ei hintoja

### 2. Vanhojen kotisivujen uudistus
- Kohteena erittäin vanhat yrityssivut (jopa 1990-2000-luvulta)
- Asiakkaat valitaan itse soittamalla – priorisoidaan sivut, joilla on jo riittävästi sisältöä valmiina (ei tarvitse "kaivaa" tietoa asiakkaalta)
- Toteutus: GitHub + Claude Code -menetelmällä, päivitetään sivu "nykypäivään"
- Tavoite: isompi työ n. 1 päivässä, pienet jälkihoidot (esim. sähköposti) voivat venyä useammalle päivälle
- **Hinta-arvio:** 300–500 €
- **Ylläpito:** GitHub-pohjainen, tarjotaan n. 99 €/vuosi (sis. alv) — verrattuna vanhan ylläpidon 200–500 €/vuosi
- **Referenssi:** promego.fi

### 3. Uusien kotisivujen toteutus
- Kokonaan uusien sivujen rakentaminen samalla GitHub + Claude Code -menetelmällä

### 4. Some-/markkinointivideot (alkuvaiheessa)
- Lyhyet markkinointivideot someen, esim. 2x30s tai 2x15s
- Käytössä GoPro 13, lisää kalustoa hankitaan
- Vielä hyvin alkuvaiheessa – ei paljon materiaalia, mainitaan sivuilla kevyesti ilman suuria lupauksia
- Yhdistyy luontosisältöön (retkeily, sukellus) osana markkinointia

## Ilme ja arvot

### Visuaalinen linja
- Luonnonläheinen, rauhallinen, minimalistinen
- Puumateriaalit / maanläheiset sävyt (henkilökohtainen kytkös: puiset esineet, luontoyhteys)
- Ei "kiiltävää" myyntipuhetta – vähän tekstiä, suoraan asiaan

### Arvot
- Avoimuus
- Rehellisyys
- Helposti lähestyttävä
- Tausta: yli 3v raittiina, aiempi yrittäjyys päättynyt konkurssiin — ei tarvitse mainita yksityiskohtia sivuilla, mutta arvo "avoimuus" nousee tästä aidosti
- Some-sisältö raittiudesta pidetään erillään yrityksen virallisesta viestinnästä

## Sivuston rakenne (ehdotus)

1. **Etusivu**
   - Lyhyt esittely: kuka olet, mitä Vidomai tekee
   - Rauhallinen, luontohenkinen visuaalinen ilme

2. **Palvelut**
   - Kotisivujen uudistus (nopea, edullinen, GitHub-ylläpito)
   - Uusien kotisivujen toteutus
   - Domain-palvelut (ei hintoja näkyville)
   - Maininta tulevista some-/markkinointivideoista

3. **Minä / Tietoa**
   - Lyhyt, henkilökohtainen mutta ammattimainen esittely
   - Yksinyrittäjä, IT-tausta
   - Arvot esiin tyylikkäästi, luontoyhteys mainittuna

4. **Yhteystiedot**
   - Puhelin, sähköposti (uusi osoite kun siirto tehty)
   - Mahdollisesti yhteydenottolomake
